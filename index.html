Interactive companions to the chapter

Sport Inference Lab

Six small apps for Understanding quantitative analysis in sport and exercise science. Each one takes a single idea from the chapter, puts it in a sport setting and lets you change the numbers and watch what happens. They run in your browser, work offline once opened, and nothing you enter leaves the page.

Using them in teaching

  • Each app opens with a worked example already loaded, followed by a short list of things to try.
  • The figures are drawn from exact calculations, apart from the p-value and confidence interval apps, which simulate studies on purpose (their “expected” values are still exact).
  • Each page is a single file. They can be linked from a virtual learning environment, saved for offline use, or opened from a USB stick. Keep them in one folder so the links between them work.
